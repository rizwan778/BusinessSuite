# Migrations

This folder holds EF Core migrations: versioned C# files that create and change the database schema.
They are **generated** by the `dotnet ef` tool and **committed** to Git together with the code change
that required them.

The folder is empty in the initial scaffold because migrations must be generated by the real EF Core
tooling on a machine with NuGet access. Create the first one from the repository root:

```powershell
dotnet tool restore
./scripts/db.ps1 add InitialCreate        # Windows PowerShell
# or
./scripts/db.sh add InitialCreate         # Linux / macOS / Git Bash
```

Then review the generated `*_InitialCreate.cs` file and commit all three generated files
(`<timestamp>_InitialCreate.cs`, `<timestamp>_InitialCreate.Designer.cs`, `AppDbContextModelSnapshot.cs`).

Rules:

- Never edit a migration that has already been applied to a shared or production database. Add a new one.
- Never delete `AppDbContextModelSnapshot.cs`.
- The integration test `MigrationTests.Model_has_no_pending_changes` fails when the model changed but no
  migration was added. Read its message: it tells you the command to run.

Full workflow (create, review, apply, roll back, production script): `docs/DATABASE_DESIGN.md`.
